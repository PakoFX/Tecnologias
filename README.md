# Principios SOLID y Conceptos de POO

¡Bienvenido! Este repositorio contiene ejemplos prácticos y ejercicios sobre los **Principios SOLID** y conceptos clave de la **Programación Orientada a Objetos (POO)**. Los ejemplos están desarrollados en lenguajes como **Java** y **Python**.

## 📁 Estructura del Proyecto

El código fuente principal se encuentra en `Tecnologias/SOLID/`, organizado en distintas carpetas, cada una enfocada en un concepto o principio específico:

- 🔹 **`single/`** - **S**ingle Responsibility Principle (Principio de Responsabilidad Única): Una clase debe tener una, y solo una, razón para cambiar.
- 🔹 **`Open/`** - **O**pen/Closed Principle (Principio de Abierto/Cerrado): Las entidades de software deben estar abiertas para su extensión, pero cerradas para su modificación.
- 🔹 **`Polimorfismo/`** - Ejemplos de polimorfismo mediante interfaces y herencia (p. ej., implementaciones de métodos de pago, tarjetas, PayPal, etc.).
- 🔹 **`ClasesAbstractas/`** - Uso de clases abstractas para definir plantillas de comportamiento y jerarquías.
- 🔹 **`HerenciaMultiple/`** - Ejemplos de cómo manejar la herencia múltiple (como en Python) y los comportamientos que surgen al heredar de múltiples clases base.
